Build a complete mobile application called **NearServe – Local Service Booking App**.

### 1. App Purpose

NearServe is a local service booking mobile application that helps users discover nearby service providers, filter services according to their requirements, view service details, and book services.

The application should have a clean, modern, professional mobile UI suitable for a college-level software project and hackathon presentation.

The main idea is:

**Discover → Filter → View Service → Book → Track Booking**

---

### 2. Technology Stack

Use the following technologies:

**Frontend**

* React Native
* Expo
* TypeScript

**Backend**

* Node.js
* Express.js

**Database**

* MySQL

**API**

* REST API using Express.js

**Development**

* VS Code / Antigravity
* Git and GitHub

Do not use Firebase as the main database.

Keep the project structure clean so the frontend and backend can be developed separately.

---
